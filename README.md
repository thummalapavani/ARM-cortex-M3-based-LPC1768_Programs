# LPC1768 Embedded C Programs

## About

This repository contains Embedded C programs developed using the LPC1768 microcontroller, based on the ARM Cortex-M3 processor core.

## Topics Covered

* GPIO Interfacing
* LED Interfacing
* LCD Interfacing
* Keypad Interfacing
* PLL Configuration
* Timer Programming
* Counter Programming
* Interrupt Programming
* UART Communication
* I2C Communication
* PWM Generation
* ADC Programming

## Software Requirements

* Keil µVision
* Embedded C
* LPC1768 Microcontroller

## Purpose

This repository documents my practical learning and hands-on experience in Embedded Systems programming.
